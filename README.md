# ICP — CRM Analysis Tool

Connect a Zoho CRM (read-only), pull all data, and visualize every signal (won vs lost, segments, pipeline, sources, activities) to decide the Ideal Customer Profile.

**Status:** v0 in progress.

## Data safety
This repo is public. Credentials (`.env`) and all exported CRM data (`data/`, `reports/`, `*.duckdb`, `*.csv`) are git-ignored and must never be committed.
