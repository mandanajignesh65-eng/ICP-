# Script 2: 3 developer tools (faceless reel)

**Format:** Faceless. Voiceover + screen recordings. ~30 seconds.

## Voiceover

**Hook:** 3 tools every developer should know that will save you hours.

**1. Excalidraw:** Need to understand how a project actually works? Open Excalidraw and draw the whole architecture. Services, APIs, database, how the data flows. Once you see it, the code makes sense.

**2. Bruno:** Testing APIs? Bruno is a simple, free API client. It works offline and saves your requests right inside your project, so your whole team has them.

**3. ZeroAI:** And if your day disappears into Slack messages and meetings, try ZeroAI. It turns those messages into tasks and blocks focus time on your calendar, so you actually get time to code.

**End:** Save this for later.
