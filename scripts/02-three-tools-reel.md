# Script 2: 3 developer tools (faceless reel)

**Format:** Faceless. Voiceover + memes + quick screen clips. ~30–35 seconds.
**Voice:** Like telling a friend over chai. Relaxed, normal speed.
**Screen style:** Messy and fun. Memes, quick cuts, random zooms. Not a clean presentation.

## Script

| Voiceover | On screen (memes + clips) |

## Tips for the edit

- Change the meme every 2–3 seconds. Keep it fast.
- Use popular Indian dev memes (Hera Pheri, Jethalal, Mirzapur) plus classic global ones (This is fine, Drake, Galaxy brain).
- Add Slack ping sounds in the ZeroAI part.
- Subtitles on screen for every line.
