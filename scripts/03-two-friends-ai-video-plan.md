# Reel 3: AI video production plan (Andrew voice, ~49 sec)

**Voiceover:** `voiceovers/reel3-two-friends-60s-bold-male.mp3`
**Format:** 9:16 vertical, 1080×1920
**Mix:** about 85% AI-generated video clips, 3 memes at punchlines, 1 real screen recording (the Zero demo from the client)
**Total clips to generate:** 12 AI clips, each 3–5 sec

---

## Fastest way to do it (4 steps)

1. **Make 2 character images first** (5 min). Use the prompts in "Step 1" below in Midjourney, Ideogram, ChatGPT images or Leonardo. Pick the best one of each. These are your **reference images**.
2. **Make the 12 scene images** (20 min). Use each scene prompt **with the reference image attached** so the two guys look the same in every scene.
3. **Turn each image into a 5-sec video** (30–40 min). Upload the scene image to an image-to-video tool (Kling, Runway, Hailuo or Google Veo) and paste the motion prompt. Generate 2 versions of each and keep the better one.
4. **Edit in CapCut** (30 min). Drop in the voiceover, put each clip on its line using the timings below, add the 3 memes, the Zero clip, subtitles and sound effects.

Tip: generate everything in the same tool and the same style so it looks like one video, not 12 different ones.
