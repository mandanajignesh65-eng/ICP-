# Script 3: Same college, 3x salary (faceless reel)

**Format:** Faceless. Voiceover + AI illustrations + screen clips + 2–3 memes. ~40 seconds.
**Voice:** Like telling a friend a story. Relaxed, natural.
**Visual mix:** Mostly AI illustrations of two characters (Dev 1 and Dev 2), plus real screen clips. Memes only at 2–3 punchlines.

---

## AI illustration prompts

Use the same style for all images so the two characters look the same in every scene.

**Style line (add to every prompt):** flat 2D cartoon illustration, soft colors, simple clean background, modern Indian tech office, vertical 9:16, consistent characters

**Characters:**
- **Dev 1:** young Indian developer, messy hair, grey hoodie, tired eyes
- **Dev 2:** young Indian developer, neat hair, navy t-shirt, calm and relaxed

**Prompts:**
1. Two young Indian developers sitting side by side at identical desks, same laptops showing a code terminal, same coffee mugs, Dev 1 in grey hoodie, Dev 2 in navy t-shirt + style line
2. Same scene, a big glowing "3x" salary tag above Dev 2, Dev 1 looking at it shocked + style line
3. Dev 1 in grey hoodie juggling a laptop, phone, coffee cup and meeting invites, many chat notification bubbles flying around, chaotic, papers flying + style line
4. Dev 2 in navy t-shirt sitting calmly with headphones, a plant on the desk, one code window open, peaceful focused mood + style line
5. Split scene: left Dev 1 exhausted at a messy desk at night, right Dev 2 closing laptop and leaving, sunset through the window + style line

---

## Tips for the edit

- Add a slow zoom or small movement to each illustration so it doesn't feel static.
- Slack ping sounds on Dev 1's scenes, calm lofi on Dev 2's scenes.
- Subtitles on every line.
- Memes only at the 3 punchlines (Pikachu, Kimi, Gigachad). Everything else is illustration or real screen clips.
