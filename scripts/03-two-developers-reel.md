# Script 3: Two developers (faceless reel)

**Format:** Faceless. Voiceover + memes + quick screen clips. ~35 seconds.
**Voice:** Like telling a friend a story. Relaxed, a little funny.
**Screen style:** Split screen when comparing. Fast meme cuts. Messy, not polished.

---

## Script

| Voiceover | On screen (memes + clips) |
|---|---|
| Two developers. Same team, same skills, same salary. | Spider-Man pointing at Spider-Man meme, labels "Dev 1" and "Dev 2" |
| Dev 1 starts the day with "hey, got a minute for a quick call?" | Slack message popping up + Michael Scott "No, God, please no" |
| Then standup. Then someone asks for the status that was already shared. | Bernie "I am once again asking" → text changed to "I am once again explaining the status" |
| Then a meeting to plan the next meeting. | "We need to go deeper" Inception meme |
| By 6 pm, maybe 20 lines of code. And completely drained. | Tired SpongeBob / Sad Pablo Escobar waiting |
| Dev 2 gets the same messages, the same meetings. | Split screen: same Slack pings on both sides |
| But blocks two hours every morning for actual coding. Slack can wait. | Kimi Räikkönen "Leave me alone, I know what I'm doing" meme |
| Ships the feature, fixes the bug, logs off on time. | SpongeBob "Ight, imma head out" |
| Now guess who gets noticed at appraisal time. | Side-eye monkey puppet meme |
| The difference was never skill. It was focus time. | "Always has been" astronaut meme |
| Dev 2 uses ZeroAI. It turns those Slack asks into tasks and blocks focus time on the calendar automatically. | Clip: Slack message → task → calendar "Deep Work" block |
| Be Dev 2. | Gigachad meme |

---

## Tips for the edit

- Use a split screen (Dev 1 left, Dev 2 right) for the comparison part.
- Slack ping sounds on Dev 1's side, calm lofi on Dev 2's side.
- Change the meme every 2–3 seconds. Subtitles on every line.
- Keep it light. The joke is on the meetings and pings, not on Dev 1.

## Caption

> Same skills. Different calendar. 📅
> Be honest, are you Dev 1 or Dev 2? 👇
