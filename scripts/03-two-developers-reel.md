# Script 3: Same college, 3x salary (faceless reel)

**Format:** Faceless. Voiceover + memes + quick screen clips. ~40 seconds.
**Voice:** Like telling a friend a story. Relaxed, natural.
**Screen style:** Split screen for the comparison. Fast meme cuts. Messy, not polished.

---

## Script

| Voiceover | On screen (memes + clips) |
|---|---|
| Two developers. Same college, same experience. Both use Claude Code every day. | Spider-Man pointing at Spider-Man, labels "Dev 1" and "Dev 2" |
| But one of them earns 3x more than the other. | Surprised Pikachu |
| And it's not because they're smarter. | "Wait, it's not about skill?" / Confused Nick Young |
| Dev 2 just ships more code. And better code. | Stonks meme |
| Here's the difference. | Zoom-in on Dev 2's screen |
| Dev 1's day looks like this. A bit of coding, then a "quick call", then Slack, then back to coding, then another meeting. Juggling ten things, finishing none. | Split screen: Dev 1 side full of Slack pings + "This is fine" dog |
| Dev 2 does three simple things. | Text: "3 simple things" |
| One. Writes down all the tasks before opening the editor. | Clip: a short to-do list being written |
| Two. Does one task at a time. No switching. | Kimi "Leave me alone, I know what I'm doing" |
| Three. Blocks two hours on the calendar every day just for coding. No meetings, no Slack. | Calendar with a "Focus time 10–12" block |
| That's it. Two hours of real focus beats eight hours of juggling. | "Always has been" astronaut |
| I found a tool that does this part for you. It's called ZeroAI. | ZeroAI logo |
| It picks up all those Slack asks as tasks and blocks deep work time on your calendar, so you can actually focus. | Clip: Slack message → task → calendar "Deep Work" block |
| Try it, and be Dev 2. | Gigachad meme |

---

## Tips for the edit

- Split screen for the comparison: Dev 1 on the left, Dev 2 on the right.
- Slack ping sounds on Dev 1's side, calm lofi on Dev 2's side.
- Change the meme every 2–3 seconds. Subtitles on every line.
- The joke is on the meetings and the juggling, not on Dev 1.

## Caption

> Same college. Same tools. 3x salary. The difference? 2 hours of focus. 📅
> Be honest, are you Dev 1 or Dev 2? 👇
